# Financial Risk Prediction

## Overview

This project explores financial risk prediction using machine learning and NLP techniques. Multiple financial datasets covering credit card default, loan default, credit card fraud, and customer attrition were combined into a unified classification dataset.

Traditional machine learning and tree-based models were compared with a pretrained BERT model for text-based classification. The project also explored class weighting and BERT fine-tuning to address the imbalanced target distribution.

## Methods

- Data preprocessing and dataset integration
- Text-based representation of financial data
- TF-IDF
- Traditional machine learning models
- Tree-based models
- Class weighting for imbalanced data
- BERT fine-tuning
- F1-score evaluation

## Technologies

**Python · Pandas · scikit-learn · PyTorch · Hugging Face Transformers · BERT · XGBoost · NLP**
